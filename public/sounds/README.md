# sounds

Typoria の効果音（key / miss / clear / perfect / combo / fever / result）と BGM は、
すべて Web Audio API のオシレーターでリアルタイムに合成しています（`src/game/audio.ts`）。
外部の音源ファイルは使用していません。

## ライセンス

合成コードはリポジトリ本体と同じライセンスです。
将来ここに音源ファイルを追加する場合は、ファイル名・出典・ライセンス（CC0 など）をこの表に記録してください。
